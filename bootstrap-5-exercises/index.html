Exercise 1.1 and 2.2

Bootstrap 5 CDN setup and bundle JS

This page links Bootstrap from the CDN and includes bootstrap.bundle.min.js so collapse, tabs, and toggles work without extra scripts.

Why the bundle matters

The bundle includes Popper and Bootstrap's plugins, so the navbar collapse, tabs, and button toggles in this solution work immediately.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
Exercise 2.1

Downloaded Bootstrap directory structure

The local asset page uses the downloaded Bootstrap files from assets/bootstrap. The CSS folder stores the compiled stylesheet, the JS folder stores the bundle, and the icons folder is where icon assets would live if you add Bootstrap Icons or another icon set.

bootstrap-5-exercises/
├── assets/
│ └── bootstrap/
│ ├── css/  compiled Bootstrap styles
│ ├── js/  Bootstrap bundle and plugins
│ └── icons/  optional icon assets folder
├── index.html
├── downloaded-bootstrap.html
└── styles.css
Local assets
  • CSS: presentation layer and utility classes
  • JS: collapse, tabs, modals, dropdowns, tooltips
  • Icons: optional SVG, font, or icon-package files
