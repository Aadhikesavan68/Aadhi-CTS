# Bootstrap 5 Exercises Solutions

This folder keeps the Bootstrap practice work separate from the rest of the repo.

## Pages
- `index.html` - CDN-based exercises and responsive component demos.
- `downloaded-bootstrap.html` - local Bootstrap asset demo using the downloaded files in `assets/bootstrap`.

## Asset layout
- `assets/bootstrap/css/bootstrap.min.css` - Bootstrap styles.
- `assets/bootstrap/js/bootstrap.bundle.min.js` - Bootstrap JavaScript plugins.
- `assets/bootstrap/icons/` - optional folder for icon assets.

## Coverage
- Exercise 1.1 - CDN setup
- Exercise 1.2 - downloaded Bootstrap files
- Exercise 2.1 - structure of CSS, JS, and icons folders
- Exercise 2.2 - bundle JS plugins
- Exercises 3 to 5 - responsive grid, layouts, alignment, reordering
- Exercises 7 to 11 - flex, typography, forms, buttons, navigation, cards
