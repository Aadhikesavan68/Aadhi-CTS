What is local here?

The Bootstrap stylesheet and JS bundle are loaded from the assets/bootstrap folder, so this page works without external CDN links.

Folder purpose

The css folder holds compiled styles, the js folder holds the bundle, and the icons folder is reserved for icon assets if you add them later.

Local CSS loaded Local JS loaded 
<link rel="stylesheet" href="assets/bootstrap/css/bootstrap.min.css">
<script src="assets/bootstrap/js/bootstrap.bundle.min.js"></script>

Asset folder note

The icons folder is included in the folder structure so this exercise mirrors a real downloaded Bootstrap setup. Add Bootstrap Icons or other SVG assets there if needed.
